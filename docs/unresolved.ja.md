# 未解読

存在は分かっているが解読していない、または一部しか解読していないもの。根拠（画面で1か所だけ変えた前後の書き出し）つきの情報を歓迎します。

## 未解読

| 項目 | 分かっていること |
|---|---|
| トラックのオートメーション | トラックのフェーダーとプラグインのオートメーションレーンは読まない |
| キーフレームのフラグ | 画面で付けたキーはすべて `0x000C0000`。補間の種類と思われる。`compose` も同じ値を書く |
| トラック単位の Dialogue Leveler | API からは設定できない。画面で設定するまでトラックの記録に `UI_…` のパラメーターがない |
| プラグインのバイパス | 挿入プラグインのバイパスの保存場所は不明 |
| プラグインの状態フラグ | 解読済みはトラック内蔵 Voice Isolation（ビット `0x10`）だけ。挿入プラグイン（`2` を観測）とほかの内蔵FX は `--all` で生値 |
| Bus のソロ・パン | Bus 表の前半に項目はあるが未確認 |
| `0x0B9` | タイムラインごとにちょうど1トラックだけ 0 以外（1、2＝そのトラック内のチャンネル）。トラックの選択（`0x0AA`）では**ない**。`unknown_0b9` として生値で出す |
| `0x13B` | 意味不明。`unknown_13b` として生値で出す |
| `0x008`／`0x009` | パン関連の可能性（−200 を書くとレベルが約 +1.5 dB 変わった） |
| `0x11B` の 0 以外の値 | 0＝エキスパンダー、0 以外はゲート表示。個々の値の意味は不明 |
| EQ のつまみ `0x333+k` | 周波数に連動。つまみ位置と思われる。使っていない |
| フェードのカーブの形 | 曲線は保存された点を通る。点が 50 % のときは直線フェードの dB 曲線の定数倍。それ以外の位置での両端と点の間の形はモデル化していない |
| 素材の `Clip` の field 15・16 | そのまま残す |

## 一部だけ較正

| 項目 | 状態 |
|---|---|
| エキスパンダーのスレッショルド `0x116` | 1点だけで ÷10 dB（`assumed`） |
| エキスパンダーのレシオ `0x253` | 実測した14点すべてが表に入っており、独立した検証はない |
| Limiter プラグインのリリース | 1値のみ（0.8829＝190.55 ms） |
| De-Esser のリアクション | 1値のみ（0.5＝medium） |
| EQ の Q | 0.8〜5.0 で当てはめ。画面の範囲の両端（0.3、10.3）は未確認 |
| Dynamics のホールド／リリース | つまみ位置 100〜250 付近は ±1 % より大きくずれることがある |

## 解決済み（参考）

- **フェードのカーブ**：番号 99／100、ビッグエンディアンの `(位置 %, レベル 0.1 dB 単位)` の点。[フェードのカーブ](clips-edits.md#fade-curves) 参照。
- **トラック Voice Isolation の有効／無効**：プラグイン記録の状態フラグのビット `0x10`。[プラグイン](plugins.md#track-voice-isolation-onoff) 参照。
- **EQ のバンド**：[換算](conversions.md) 参照。以前の `eq_band1_type` → `0x0DE` という対応は誤り（その項目は処理順）で、削除しました。

## `compose` が対応していないもの

推測せずに拒否します：重なるクリップ、中央揃えの Cross Fade 0 dB 以外のトランジション、曲線のフェード、1ファイルに複数の音声ストリーム、複数トラックでの同じ素材、秒やサブフレームでの位置指定、チャンネル数を変えるときの既定でないチャンネル割り当て、[対応形式](media.md#supported-formats) 以外の素材、テンプレートのオーディオトラック上のオーディオクリップとトランジション以外のアイテム。

なお、FCPXML の `fadeIn`／`fadeOut` は Resolve が読み込み時に無視するため、その経路ではフェードを持ち込めません。
