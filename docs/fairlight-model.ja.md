# Fairlight ミキサー（FLStudioModelBA）

タイムラインの Fairlight ミキサー全体（トラック・Bus・内蔵EQ と Dynamics・プラグイン・ルーティング）は1つのバイナリ、`Sm2Sequence` の `FieldsBlob` 内の `FLStudioModelBA` に入っています（[.drp と Project.db](file-format.md) 参照）。`qCompress` を展開すると、drpkit が読む2種類のデータ、**チャンネル設定表**と**プラグイン記録**が出てきます。

項目番号と換算の機械可読な正本は [`drpkit/fairlight_map.yaml`](https://github.com/higuchiki/drpkit/blob/main/drpkit/fairlight_map.yaml) です。[下の項目一覧](#all-channel-items) はこのファイルから自動生成しています。

## チャンネル設定表

リトルエンディアンのレコードの連続です。

```text
u32 1 | u32 項目番号 | u32 列数 | 列数 × int32
```

- **列**＝チャンネル。ステレオトラックは同じ名前の2列、モノラルは1列。
- 項目 `0xBC` だけは例外で、列数ぶんの長さ付き UTF-8 文字列＝チャンネル名を持ちます。表を見つけ、見分ける手がかりです。
- 1つの表に同じ項目番号が2回出たら、最初のものを使います。

表は複数あり、名前で見分けます。

| 表 | 名前の例 |
|---|---|
| トラック表 | トラック名 |
| Bus 表 | `Bus 1`・`Bus 2`…（項目 `0x1D` から始まる） |
| その他 | `VCA…`・`Mapping…`・`Folder…`（読まない） |

reader の探し方：すべての `0xBC` レコードを見つけ、レコード単位で後ろ向きにたどって表の先頭を求め、そこからレコードの形が崩れるまで前向きに読みます。

### Bus 表の前半

Bus 表は2つに分かれています。前半（フェーダー `0x001`・ミュート `0x002`・前段ゲイン `0x019`・パン…）は、ブロブ内の**もっと前に離れて**、見出し `u32 0, u32 7` の直後に置かれます（7 は Bus の種別番号で、プラグインの所属と同じ番号）。reader は Bus 表より前にある、列数が Bus の数と同じその並びのうち最後のものを取り、Bus のストリップに合流させます。

### ストリップ番号とルーティング

| 項目 | トラック | Bus |
|---|---|---|
| ストリップ番号 `0x458` | 0 … n−1（ステレオトラックの2列目は −1） | トラック数 + 1 |
| Bus のチャンネル数 `0x1B4` | — | そのまま（2＝ステレオ） |
| 出力接続／出力先 `0x400`／`0x40B` | フラグ／Bus 番号（0＝Bus 1、−1＝なし） | |

## プラグイン記録 {#plugin-records}

プラグインの各インスタンス（トラックと Bus の挿入プラグイン、トラック内蔵FX）は ASCII のタグ `bmd:<名前>:<ID>` として現れます。

```text
タグからの位置    内容
  −12            u8 種別 | u8 列 | u8 0 | u8 スロット
   −4            u32 所属（2＝ミキサーのインスタンス）
    0            名前欄 256 バイト（"bmd:<名前>:<ID>" を NUL 埋め）
  256            int32 × 4：プラグイン画面の位置と大きさ（一度も開いていなければすべて −1）
  272            u32 状態フラグ
  ...            次のタグまでパラメーター
```

| 欄 | 値 |
|---|---|
| 種別 | `0`＝トラック、`7`＝Bus |
| 列 | 所属するストリップの、その表での列 |
| スロット | `0〜5`＝挿入スロット1〜6、`6〜10`＝トラック内蔵FX：6 Voice Isolation、7 Dialogue Leveler、8 Dialogue Separator、9 Music Remixer、10 Ducker |
| 所属 | ミキサーのインスタンスは `2`、内蔵FX は `0`／`1`。それ以外は雛形（AutoMix のプリセットなど）なので無視 |
| パラメーター | 64 バイトの NUL 埋めの名前（`Plugin::PARAM`、または `UI_BAS_PRESET` のような `::` なしの名前）＋リトルエンディアン float32 の**正規化値 0〜1** |
| 状態フラグ | トラック内蔵 Voice Isolation：ビット `0x10` が立っていれば無効、なければ有効（無効中も量は保持）。使っていない内蔵スロットも `0x10`。挿入プラグインとほかの内蔵FX では未解読（`--all` で生値表示） |

つまみの換算は [プラグイン](plugins.md) にあります。

## 確度記号 {#confidence-marks}

換算した値にはすべて、どう確かめたかを示す記号が付きます。

| 記号 | `conf` | 意味 |
|---|---|---|
| 無印 | `direct` | 保存値そのまま、または定数倍。既知の画面値と照合済み |
| ² | `two_point` | 2点以上の既知点で一次式・対数式を確定 |
| ※ | `calib`／`law` | 画面で読んだ値との対応表（Dynamics は補間）。表にない保存値は `未較正(raw=…)` |
| ? | `assumed` | 1点のみ・範囲は仮定。参考値 |
| ✗ | `raw`／`uncal` | 意味未確定・未較正。生値のみ |

## 全チャンネル項目 {#all-channel-items}

`drpkit/fairlight_map.yaml` から生成（`python tools/gen_map_docs.py`）。項目番号はトラック表と Bus 表で共通です。種類：`scale`＝生値×定数、`flag`＝0/1、`flag_inv`＝反転フラグ、`enum`＝対応表、`affine`＝a＋b×生値（範囲で頭打ち）、`law`＝内蔵 Dynamics の換算、`raw`＝未解読。

### 項目の並び

| 種類 | 番号 | 備考 |
|---|---|---|
| EQ バンド k の有効（k＝1〜6） | `0x100+k` | 1＝有効 |
| EQ バンド k のフィルター種類 | `0xF8+k` | 1 ローシェルフ、2 ベル、3 ハイシェルフ、4 ノッチ、5 ローパス（バンド6の既定）、6 ハイパス（バンド1の既定） |
| EQ バンド k の周波数 | `0xF0+k` | Hz そのまま |
| EQ バンド k のゲイン | `0xE0+k` | ÷10 dB |
| EQ バンド k の Q | `0xE8+k` | Q ≈ −0.615 + 0.06567 × 生値 |
| EQ バンド k のレンジ（k＝2〜5） | `0x287+k` | 0 L、1 ML、2 MH、3 H |
| EQ バンド1／バンド6のスロープ | `0x4BE`／`0x4C3` | 0＝6、1＝12、2＝18、3＝24 dB/oct |
| EQ バンド k のつまみ（生値） | `0x333+k` | 周波数に連動。Hz の自然対数1あたり約94、0〜256。つまみ位置と思われ、表示には使わない |

各換算をどう確かめたかは [換算](conversions.md)。
