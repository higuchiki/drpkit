drpkit

Read and edit DaVinci Resolve project files without opening Resolve: .drp exports can be read and written; the disk-database Project.db is read only (write and compose work on .drp files only).

DaVinci Resolve のプロジェクトファイルを Resolve を起動せずに扱うツールです。.drp（書き出したプロジェクト）は読み書き、ディスクDBの Project.db は読み取りのみです（write・compose は .drp だけが対象）。

Unofficial 非公式 MIT License Python 3.9+

What it does

できること

drpkit read

Fairlight mixer settings (tracks, buses, built-in EQ / Dynamics, plugins) and edit information (clips, fades, keyframes, transitions, clip colors, timeline markers), converted to the values shown in the UI.

Fairlight ミキサー設定（トラック・Bus・内蔵EQ・内蔵Dynamics・プラグイン）と編集情報（クリップ・フェード・キーフレーム・トランジション・クリップ色・タイムラインマーカー）を、画面に表示される値に換算して出力します。

drpkit read project.drp
drpkit read project.drp --json
drpkit read project.drp --edits
drpkit read Project.db --timeline "Main"

drpkit compose

Build a new .drp from a template project, your audio files and a cut list. The template's whole mixer is kept byte for byte.

テンプレートプロジェクト・音声ファイル・カット表から新しい .drp を組み立てます。テンプレートのミキサーはそのままバイト単位で保持されます。

drpkit compose TEMPLATE.drp OUT.drp --cuts cuts.json \
    --media 1=host.wav --media 2=guest.flac

drpkit write

Analysis only: write raw values into the mixer tables of a copy of a .drp, to build conversion tables.

解析専用コマンド。.drp のコピーのミキサー表に生の値を書き込み、変換表を作るために使います。

drpkit write IN.drp OUT.drp --set 'Track1:0x10d=51996'

Checked with DaVinci Resolve Studio 21.1.1. The free version is not verified. drpkit only touches files, never the Resolve application or its scripting API.

Resolve Studio 21.1.1 で確認。無償版は未検証です。ファイルだけを扱い、Resolve 本体やスクリプトAPIは一切使いません。

Install

インストール

pip install git+https://github.com/higuchiki/drpkit.git
drpkit --version

compose needs ffprobe (part of FFmpeg) on PATH. Reading clip effects and compressed markers from a Project.db needs Python 3.14+ or the zstandard package.

compose には PATH 上の ffprobe（FFmpeg）が必要です。Project.db のクリップFXと圧縮マーカーを読むには Python 3.14 以上、または zstandard パッケージが必要です。

Safety

安全性

  • read never modifies its input: a .drp is opened as a zip for reading, a Project.db read-only and immutable.
  • write and compose never overwrite — the output path must not already exist. The result is written to a temporary file, read back and verified (compose compares every clip with the cut table), then moved into place in one step; on any error no output file is left.
  • Import results into a separate project library used only for testing, and keep a backup of the original.
  • read は入力を一切変更しません。.drp は読み取り専用で zip として開き、Project.db は読み取り専用・変更不可で開きます。
  • write と compose は上書きしません（出力先が既にあれば拒否）。一時ファイルに書き出して読み直し・検証し（compose は全クリップをカット表と照合）、合格したときだけ一度に出力名へ移します。失敗時は出力ファイルを残しません。
  • 結果は本番とは別の検証用プロジェクトライブラリに読み込み、原本のバックアップを保持してください。

Prior work

先行例

samuelgursky/davinci-resolve-mcp (MIT) already works with the same underlying data to read and create bus configuration and routing. Many thanks to that project for showing that this data is reachable. drpkit covers a different area — built-in Dynamics and EQ converted to UI values, fader, solo, processing order, plugin knobs and track Voice Isolation state, plus edit information and markers — identified independently. If you need to build buses or change routing, use davinci-resolve-mcp.

samuelgursky/davinci-resolve-mcp（MIT）は同じ内部データを扱い、Bus の構成・ルーティングの読み書きを実装しています。このデータが読み取れることを示してくれた同プロジェクトに感謝します。drpkit は別の領域（内蔵Dynamics・EQの画面値換算、フェーダー、ソロ、処理順、プラグインのノブ、トラックのVoice Isolation状態、編集情報、マーカー）を独自に特定して扱っています。Bus の構成やルーティング変更が必要な場合は davinci-resolve-mcp を使ってください。
